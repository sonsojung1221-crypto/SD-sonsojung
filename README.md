# 무음 카메라

셔터음 없이 사진을 찍는 웹 앱(PWA)입니다. 카메라 영상 프레임을 canvas로 캡처하기 때문에 소리가 나지 않습니다.

## 기능
- 무음 촬영 (화면 깜빡임으로만 피드백)
- 전/후면 카메라 전환, 3초/10초 타이머
- 사진은 기기(IndexedDB)에만 저장, 갤러리에서 보기/저장/삭제
- 홈 화면에 추가하면 앱처럼 사용 가능 (오프라인 지원)

## 스텔스 모드 / 영상
- 🌑 버튼: 화면이 완전히 검게 변합니다 (화면 꺼짐 방지 사용). 검은 화면에서
  - 위쪽 절반 터치: 사진 촬영
  - 아래쪽 절반 터치: 영상 촬영 시작/종료
  - 1.5초 길게 누르기: 스텔스 해제
- 웹 앱은 볼륨 버튼을 읽을 수 없어, 볼륨 키(업=사진, 다운=영상)는 키 이벤트를 전달하는 일부 기기에서만 동작합니다.

## 실행
카메라는 HTTPS 또는 localhost에서만 동작합니다.

    python3 -m http.server 8000   # http://localhost:8000

> 참고: 일부 국가에서는 몰래 촬영을 금지합니다. 타인의 동의 없이 촬영하지 마세요.
